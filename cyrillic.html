Статичен уеб сайт

HTML, CSS Grid, JavaScript, адаптивен дизайн и български вариант на кирилицата

Българска форма на кирилицата

Какво означава това?

Някои шрифтове показват кирилицата с руска или обща славянска форма. При българската форма някои букви, например „д“, „т“, „г“ и „л“, изглеждат по-близо до начина, по който сме свикнали да ги виждаме в български текстове.

За да може браузърът да избере правилните локализирани форми, в HTML документа е зададено lang="bg".

Примери

Файлове с разширения .jpg и .jpeg съдържат компресирани изображения. Размерът трябва да е подходящ за Уеб.

Откъде можем да намерим подходящи шрифтове?

  • Google Fonts
  • localfonts.eu
  • 1001fonts.com

Важно е да се проверява лицензът на шрифта. Ако пише „free for personal use only“, не е добра идея шрифтът да се разпространява публично като част от проект.

Как включваме шрифт в статичен сайт?

В този проект шрифтът е включен чрез @import в CSS файла, тъй като е част от библиотеката на Google Fonts:

@import url('https://fonts.googleapis.com/css2?family=Sofia+Sans:wght@400;700&family=Unbounded:wght@700;900&display=swap'); body { font-family: 'Sofia Sans', Arial, sans-serif; }

Освен това, в CSS файла е добавен и свободен шрифт от библиотеката на Гугъл, който се зарежда директно от файловете на сайта като пример за правилното ползване заради GDPR (според Google AI). По този начин се ползват и други шрифтове, чиито source файл е качен на нашия сървър.

@font-face { font-family: "Cormorant Infant"; src: url('fonts/Cormorant_Infant/CormorantInfant-VariableFont_wght.ttf') format('truetype'); font-weight: 400; font-style: normal; } .display-title { font-family: "Cormorant Infant"; color: #4f5fa8; letter-spacing: 0.04em; }
